# BoxForever — formerly HakuX-Mali

Transition build 1.9.1, Android code42. It changes the app name, icon, and artwork while retaining the Android app ID, signing certificate, and data directory of HakuX-Mali 1.9.

If you installed HakuX-Mali 1.9 from this repository, open Settings → App → Check for updates. You can also download the APK from this release and install it over your current copy. Keep the previous app installed. After updating, look for the green BoxForever cube with the letter F.

The transition build's updater looks for later BoxForever releases at the current GitHub address and the future `Wannamingo/BoxForever` address. The library, per-game settings, export formats, and save-state slots continue to use the existing data.

In ES-DE, **HakuX-Mali (Standalone)** still launches the emulator. The updated configuration also offers **BoxForever (Standalone)**.

BoxForever is an independent fork of [rfandango/hakuX](https://github.com/rfandango/hakuX). Use `SHA256SUMS.txt` to verify the downloaded APK.
