# BoxForever 1.0.4

Android build 47 for ARM64.

## Interface

- Added Spanish and Brazilian Portuguese. Open **Settings → Application → Interface language** and select **Español** or **Português (Brasil)**. The Xbox game language has its own setting.
- Translated setup, the library, in-game menus, global and per-game settings, the controls editor, the driver screen, save messages, and calibration. Logs, low-level driver diagnostics, and externally supplied descriptions retain their source language.
- **Settings → Application → Back up all settings** saves the touchscreen layout, controller mappings, shortcuts, theme, language, HUD, and global and per-game settings in one JSON file. Save the file to Downloads or an SD card before reinstalling. Game images, saves, and installed GPU drivers are stored separately. Select your game folders again after reinstalling.
- The eye button is off by default. Enable it in the touchscreen editor to place and resize it. It hides or restores the controls directly in-game. All buttons support 0–100% opacity. At 0%, a button still accepts touch and remains visible in the editor.

## Game compatibility

- XISO lookup now follows long directory-index chains. It detects cyclic entries in damaged images and finishes the search.
- On Vulkan drivers without `hostQueryReset`, occlusion queries are reset in the command buffer. Incomplete results still use the existing fallback.
- The selected Xbox AV pack is applied at game launch and after restoring a save state. The save-state format is unchanged.
- Added regression coverage for Fable's unaligned vertex formats using BoxForever's existing repacking path.
- On Vulkan device loss, BoxForever cancels unfinished readbacks and wakes blocked threads. After a transient presentation timeout, it keeps the submitted frame until GPU completion is confirmed.

Ported [hakuX #45](https://github.com/rfandango/hakuX/pull/45), [#47](https://github.com/rfandango/hakuX/pull/47), and [#48](https://github.com/rfandango/hakuX/pull/48). Added regression coverage for [#46](https://github.com/rfandango/hakuX/pull/46).

## Validation

- On an RG477M running Android 14, verified the upgrade from BoxForever 1.0.1. The library retained 42 games, and **Syberia** loaded the existing slot 2 with Unified 0.4.91. Settings export and restore passed, and the eye button hid and restored on-screen controls in-game.
- Passed 160 Android tests, 16 Vulkan scenarios with a mock driver, and a vCPU wake-up check. Signed with the BoxForever release key and existing certificate lineage.
- The RG477M check used ADB. Standard Package Installer behavior with Play Protect and the reported POCO X4 GT stalls still require separate verification.
