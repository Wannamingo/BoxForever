# HakuX-Mali 1.8

Android versionCode **40**. Supported handhelds include the ANBERNIC RG477M, RG476H, RG Vita Pro and RG Rotate.

## Unified driver

- Bundles Unified 0.4.53 for ARM64 and Android 12 (API 31) or later. It fixes vertex attribute divisors, including non-power-of-two divisors. [Unified source and original driver package](https://github.com/Wannamingo/Unified/releases/tag/v0.4.53)
- Select **Settings → Graphics → GPU driver → Unified 0.4.53**, then start the game again. Updating preserves the current driver selection. The system driver, earlier bundled drivers including 0.4.50, and manual ZIP import are still available.

## Interface and graphics

- **Restart** in the pause menu and settings launches the current game with new settings without returning to the library. Internal resolution, the FPS limit, FXAA and the upscaling filter come from emulator settings. Restart requires confirmation.
- Pause-menu actions scroll inside the panel. The heading stays fixed, and the last action is fully visible when scrolled to the bottom.
- Internal resolution changes in 0.5× steps, including 1.5×. Halo 2 has fixes for fog and the scope overlay.
- HakuX-Advanced fixes cover swapchain resizing, per-surface texture scaling, and Arm Vulkan compatibility. The release also improves Vulkan timeline diagnostics, update validation, and shader status messages.
- The library launch chooser, manual driver selection, HUD and up-to-120 FPS cap remain available. Restart preserves game saves and emulator save states.

## Validation

- Unified 0.4.53 passed 156 rendering cases with the same checksum on each of the RG477M (Mali-G615), RG476H (Mali-G57) and RG Rotate (Mali-G52).
- Need for Speed: Most Wanted loaded a saved race on all three. RG477M and RG476H were driven briefly. The RG Rotate check used a separate HakuX installation at 2× with the car stationary. These checks cover launch and rendering.
- On RG477M, Restart applied the change from 2× to 1.5× in Burnout 3 without opening the library. The top and bottom of the pause menu were also checked.
- The Halo 2 fixes were checked on RG477M at 1× and 1.5×.

The release contains no BIOS, game images or user saves.
