# BoxForever 1.0.5

Сборка Android 48 для ARM64.

- Исправлены тёмные многоугольники вокруг теней в Conker: Live & Reloaded на драйверах без произвольного цвета границы RGB565. Отдельная проверка на RG Rotate подтвердила нормальную тень с Unified 0.5.1 при 1× на исходном ядре. В выбранном наборе CTS на Rotate получено 24 Pass, 0 Fail и 21 NotSupported, как на штатном Vulkan.
- Unified 0.5.1 G52 Border Lab добавлен в список встроенных драйверов. Выберите его в **Настройки → Драйвер GPU** и перезапустите игру.
- Добавлен экспериментальный Hor+ для игр 4:3. Доступны 3:2, 16:10, 16:9 и 21:9. Режим расширяет поле зрения в распознанных 3D-сценах, сохраняет пропорции экранного интерфейса и по умолчанию выключен. Для Need for Speed: Underground 2 предусмотрена отдельная коррекция спидометра и мини-карты.
- Сокращено блокирующее ожидание вывода кадра. Готовый кадр остаётся в очереди до следующей попытки вывода. Добавлена диагностика длительного ожидания изображения Vulkan. Долгая остановка из отчёта The Simpsons: Hit & Run в контрольной серии на RG477M не воспроизвелась.

APK использует прежний идентификатор пакета и релизную цепочку подписи для обновления поверх 1.0.4.
