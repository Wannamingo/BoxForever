# BoxForever 1.0 — formerly HakuX-Mali

BoxForever is the new name of the original Xbox emulator for Android. This release introduces the green cube icon, refreshed project pages, and an About BoxForever entry in Settings. It retains the Android app ID and signing certificate used by HakuX-Mali 1.9.

Android versionCode 43. Transition build 1.9.1 can update to BoxForever 1.0 from Settings. If you are still using HakuX-Mali 1.9, download the signed APK from this release and install it over your current copy. Keep the previous app installed so Android preserves its data.

In ES-DE, existing **HakuX-Mali (Standalone)** assignments still launch the emulator. The updated Microsoft Xbox configuration also offers **BoxForever (Standalone)**.

BoxForever is an independent fork of [rfandango/hakuX](https://github.com/rfandango/hakuX). Games, BIOS files, hard disk images, and personal saves are excluded. Use `SHA256SUMS.txt` to verify the APK.
