# BoxForever 1.0.5

Android build 48 for ARM64.

- Fixed dark polygons around shadows in Conker: Live & Reloaded on drivers that cannot supply the requested RGB565 border color. Unified 0.5.1 also rendered the correct shadow in a separate RG Rotate check at 1× using the original core. The selected Rotate CTS suite matched system Vulkan with 24 Pass, 0 Fail and 21 NotSupported.
- Unified 0.5.1 G52 Border Lab is available under **Settings → GPU driver**. Restart the game after selecting it.
- Experimental Hor+ for 4:3 games adds 3:2, 16:10, 16:9 and 21:9. It widens the view in recognized 3D scenes and preserves HUD proportions. It is off by default. Need for Speed: Underground 2 has dedicated corrections for the speedometer and minimap.
- Reduced blocking while presenting frames. A ready frame remains queued for the next presentation attempt. Added logging for long Vulkan image acquisition waits. The prolonged freeze reported in The Simpsons: Hit & Run did not reproduce during the RG477M comparison.

The APK retains the existing package ID and release signing lineage for updates from 1.0.4.
