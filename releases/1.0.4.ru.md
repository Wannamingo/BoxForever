# BoxForever 1.0.4

Сборка Android 47 для ARM64.

## Интерфейс

- Добавлены испанский и португальский (Бразилия). Выберите **Настройки → Приложение → Язык интерфейса → Español** или **Português (Brasil)**. Настройка языка игр Xbox находится отдельно.
- Переведены начальная настройка, библиотека, меню игры, настройки эмулятора и отдельных игр, редактор кнопок, окно драйверов, сообщения о сохранениях и калибровке. Журналы, диагностические детали драйверов и получаемые извне описания сохраняют язык источника.

## Совместимость игр

- Поиск файлов в XISO проходит длинные цепочки записей каталога. Повреждённая циклическая ссылка завершает обход вместо бесконечного ожидания.
- На драйверах Vulkan без `hostQueryReset` запросы видимости сбрасываются в командном буфере. Для неполных результатов сохраняется защитное поведение.
- Выбранный видеокабель Xbox применяется при запуске игры и после восстановления состояния. Формат слотов не менялся.
- Добавлена проверка перепаковки невыровненных форматов вершин Fable. Используется существующая обработка BoxForever.

Перенесены изменения из [hakuX #45](https://github.com/rfandango/hakuX/pull/45), [#47](https://github.com/rfandango/hakuX/pull/47) и [#48](https://github.com/rfandango/hakuX/pull/48). Для случая [#46](https://github.com/rfandango/hakuX/pull/46) добавлен регрессионный тест.

## Проверки

- Проверены обновление HakuX-Mali 1.9, переключение обоих новых языков и сохранение выбора после перезапуска в тестовом Android-эмуляторе.
- Пройдены 146 тестов Android и четыре отдельные проверки ядра. Пакет подписан релизным ключом BoxForever с прежней цепочкой сертификатов.
- Игровые проверки на физических устройствах и оценка Play Защиты для этого APK не проводились.
