# BoxForever — ранее HakuX-Mali

Переходная сборка 1.9.1, Android code42. Она меняет имя приложения, значок и оформление, сохраняя идентификатор Android, подпись и каталог данных HakuX-Mali 1.9.

Если установлена HakuX-Mali 1.9 из этого репозитория, откройте «Настройки → Приложение → Проверить обновления». Можно также скачать APK из этого выпуска и установить его поверх прежней версии. Оставьте прежнее приложение установленным. После обновления ищите зелёный куб BoxForever с буквой F.

Встроенный обновлятор переходной сборки ищет следующие выпуски BoxForever по текущему адресу GitHub и по будущему адресу `Wannamingo/BoxForever`. Библиотека, индивидуальные настройки, форматы экспорта и игровые слоты продолжают использовать прежние данные.

В ES-DE прежний пункт **HakuX-Mali (Standalone)** продолжает запускать эмулятор. Обновлённые конфигурации также предлагают **BoxForever (Standalone)**.

Проект — независимый форк [rfandango/hakuX](https://github.com/rfandango/hakuX). Для проверки загрузки APK используйте `SHA256SUMS.txt`.
