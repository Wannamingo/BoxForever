# BoxForever 1.0.6

Android build 49 for ARM64.

- The APK includes **MaliSX2 0.6.1** and **Unified 0.5.1**. **Settings → GPU driver** lists System Vulkan, both bundled drivers, and ZIP import on every model. Driver runtime compatibility depends on the GPU, firmware, and Android version required by the package.
- If an update removes the selected bundled driver, BoxForever switches to System Vulkan. Imported packages and selections of Unified 0.5.1 are preserved.
- Improved experimental **Hor+** for 3:2, 16:9, 16:10, and 21:9. It widens recognized perspective scenes. Pre-rendered frames and full-screen menus retain their original proportions. Related HUD elements such as gauges and the minimap keep their layout.

If the updater in BoxForever 1.0 or 1.0.1 reports a certificate error, download the official signed APK and use the Android package installer to install it over your current copy. The package ID and signing lineage with installed-data capability are preserved.
